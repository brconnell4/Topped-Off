# Changelog

## v0.1
- Initial release.
- Set target counts per item; auto-buys the shortfall at any vendor that sells them.
- Works with anything a vendor sells for gold (food, water, ammo, reagents, poison mats, etc.).
- Gold reserve so it never spends below a set amount.
- Enable/disable and remove items individually.
- Per-character lists (mage and rogue stay separate).
- Movable window; opens with `/to` or from ESC → Options → AddOns → Topped Off.
- Add items by typing a name, or shift-click / drag from your bags.
